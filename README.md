# Motor Speech Overlay

> **Tri-Platform Agent Skill** for Claude Desktop / Code, Grok CLI, and Google Antigravity / Gemini.  
> Neurological Motor Speech Variation Profiling — Models clinical neurogenic and motor-speech variations (spastic, flaccid, ataxic, hypokinetic, hyperkinetic dysarthria, apraxia) as parameter modifiers that interface with core biometric profiles.

---

## Overview

`motor-speech-overlay` provides standardized capabilities across conversational AI platforms:
- Clinical dysarthria taxonomy and acoustic perturbation transformation matrices.
- Articulatory imprecision, vowel space reduction, and speech rate dysregulation modifiers.
- Hypernasality and phonatory instability (tremor, strain-strangled quality) modeling.
- Ethical usage guidelines and therapeutic validation framework.
- Standardized motor_speech_overlay.json parameter schema.
- Tri-platform NTFS junctions connecting Claude, Grok, and Antigravity.
- Standard documentation suite: SKILL.md, HOW_TO_USE.txt, IMPLEMENTATION_PLAN.md, and README.md.

---

## Tri-Platform Architecture

Zero duplicate code across platforms. Canonical source resides in `.agents`:
- **Canonical Source**: `C:\Users\<you>\.agents\skills\motor-speech-overlay`
- **Claude**: `C:\Users\<you>\.claude\skills\motor-speech-overlay` (NTFS Junction)
- **Grok**: `C:\Users\<you>\.grok\skills\motor-speech-overlay` (NTFS Junction)
- **Antigravity**: `C:\Users\<you>\.gemini\config\skills\motor-speech-overlay` (NTFS Junction)
